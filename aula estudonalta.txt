                         Escopo de Variáveis

variavel global = {por mais que seja declarada fora de uma função ela faz parte do programa principal}

variavel local = {reconhece os valores apenas aonde foram declarados}

exemplo:
def teste(b):
     b+= 4
     c = 2  {escopo local:a = 5, b = 9 e c = 2
               reconhece todos os valares inclusive o valor a mesmo que seja declarado fora
                da função ja que o valor a é reconhecido como valor global}

a = 5
teste(a) {escopo global: a = 5
               reconhece apenas o valor de a ja que ele era o unico valor no escopo global}

* CUIDADO caso um variavel seja declarada no escopo local ela passa ser uma outra variavel
exemplo:
def teste(b):
     a = 8
     b+= 4
     c = 2  {escopo local:a = 8, b = 9 e c = 2}

a = 5
teste(a) {escopo global: a = 5
               variavel a continua valendo 5 mesmo que na função ele tenha recebido outro valor}

caso queira que o a local seja considerado o a variavel global use o comando:
(global variavel)

exemplo:
def teste(b):
     global a
     a = 8
     b+= 4
     c = 2  {escopo local:a = 8, b = 9 e c = 2}

a = 5
teste(a) {escopo global: a = 8
               variavel mudou de valor ja que mesmo localmente voce fez o python considerar ela
               globalmente
